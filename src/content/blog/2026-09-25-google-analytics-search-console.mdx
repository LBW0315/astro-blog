[ブログを公開](/blog/2026-09-19-https-acm-cloudfront/)したあと、**Googleアナリティクス**と**Google Search Console**を入れました。

どちらもよく名前を見る道具ですが、正直、入れる前は違いが分かっていませんでした。「アクセス解析でしょ」くらいの認識です。

入れてみて、**この2つは見ている場所がまったく違う**ことが分かりました。そして数字が見えるようになったら、思っていたよりずっとモチベーションに効きました。

## 2つは、見ている場所が違う

一番の発見はここでした。

誰かが自分のブログにたどり着くまでには、いくつか段階があります。検索する → 検索結果に出る → クリックする → ページが開く → 中を読む。この一本道のうち、**2つの道具が受け持っている区間が違います**。

<SearchToReadFlow />

**Search Consoleは、検索結果までの話**です。自分のページが検索結果に何回出たか、そのうち何回クリックされたか、何番目に表示されているか。**まだ誰も来ていない段階**を見ています。

**Googleアナリティクスは、開いたあとの話**です。何人が来たか、どのページを見たか、どれくらい滞在したか。**来てからの動き**を見ています。

並べるとこうなります。

| | Search Console | Googleアナリティクス |
| --- | --- | --- |
| 見ている場所 | Google検索の中 | 自分のブログの中 |
| 分かること | 表示回数、クリック数、掲載順位、検索されたことば | ユーザー数、どのページが読まれたか、どこから来たか |
| 元になるデータ | Googleが持っている検索のデータ | ページに埋めたタグが送るデータ |
| 答えられる質問 | 「検索でどう見えている？」 | 「来た人は何をした？」 |

つまり、**「検索で見つけてもらえているか」を見るのがSearch Console、「来た人が何を読んだか」を見るのがGoogleアナリティクス**、という分担です。

<Callout type="note">
	この2つは数字が合いません。Search Consoleのクリック数とGoogleアナリティクスのセッション数（訪問の数）を比べると、だいたいズレます。Googleアナリティクスには**Google検索以外から来た人も入る**こと、Search Consoleは**通常の期間表示が太平洋時間で集計されている**ことなど、理由はいくつもあります。合わないのが普通だと思っておくのがよさそうです。
</Callout>

## 自分のアクセスも数えていた

数字を見ていて、途中で気づいたことがあります。

**自分でページを開いた分も、ぜんぶ数に入っていました。**

考えてみれば当たり前です。記事を書いたあと、表示確認のために自分で何度も開きます。スマホでも見ます。その全部が、来た人の数として数えられていました。

<InternalTrafficFilter />

1日に数人という規模だと、これはかなり効きます。5人のうち3人が自分、みたいなことが起きます。**それだと何を見ているのか分かりません。**

Googleアナリティクスには、これを除外する設定があります。自宅回線のIPアドレスを登録しておくと、そこからのアクセスを数えないようにできます。

ここで登録するのは、**外から見える側のIPアドレス（パブリックIPアドレス）**です。パソコンの設定画面に出てくる `192.168.◯.◯` のような家の中だけの番号ではありません。

やることは2段階でした。

1. **管理 → データの収集と修正 → データストリーム**から自分のサイトのストリームを開き、**タグ設定を行う → すべて表示 → 内部トラフィックの定義**で、自宅回線のIPアドレスを登録する
2. **管理 → データの収集と修正 → データフィルタ**にある内部トラフィックのフィルタを、**「テスト」から「有効」に切り替える**

<Callout type="warning">
	落とし穴はここです。**1だけやっても除外されません。**IPアドレスを登録するのは「このアクセスは内部です」と印を付けるだけで、その印が付いたものを実際に捨てるかどうかは2のデータフィルタが決めています。作った直後のフィルタは「テスト」状態なので、**有効にしないと数はそのまま**です。私も最初、1で終わったつもりになっていました。
</Callout>

<Callout type="tip">
	「テスト」は飛ばしていい段階ではなく、**有効にする前の確認用**です。レポートを「テストデータのフィルタ名」で絞ると、自分が登録したIPのアクセスだけがちゃんと引っかかっているかを見られます。というのも、**有効にしたあとの除外は取り消せません**。除外された分は処理そのものから外れるので、あとからGoogleアナリティクスでもBigQueryでも見られなくなります。番号を1桁間違えたまま有効にすると、外の人のアクセスを捨て続けることになります。
</Callout>

自分のIPアドレスは「[確認くん](https://www.ugtop.com/spill.shtml)」のようなサイトか、検索で「IPアドレス 確認」と調べれば出てきます。

<Callout type="tip">
	自宅のIPアドレスは、**プロバイダの都合で変わることがあります**。ルーターを再起動したタイミングで別の番号になっていた、ということが起こります。ある日また自分の数が混ざり始めたら、まずここを疑うのがよさそうです。固定IPでない場合は、たまに見直すものだと思っておくくらいがちょうどいいのかもしれません。
</Callout>

設定が数字に反映されるまでは時間がかかります。公式には**24〜36時間かかることがある**と書かれています。切り替えてすぐ確認して「変わってないぞ」と焦りましたが、置いておいたら落ち着きました。

## 1日数人でも、うれしい

ここが正直、一番書きたかったところです。

除外の設定をしたあとの数字は、**1日に数人**です。桁が増える気配はまったくありません。

それでも、**うれしいです。**

自分で書いたものを、知らない誰かが開いて読んでいる。しかもそれが数字として画面に出る。これは思っていたよりずっと効きました。

書く前は、正直「誰にも読まれないだろうな」と思っていました。検索に出るようになっても、**出ているだけで誰もクリックしていない状態**を想像していました。実際にクリックされて、開かれて、読まれているらしいと分かったときは、**急に世界が広がった感じ**がしました。

<Callout type="note">
	数字が出ることには副作用もあると思っています。数字を上げること自体が目的になると、書きたくないものを書き始めそうです。いまは1日数人なので、たぶんまだその心配はありません。
</Callout>

数字が見えると、次に書くときの気持ちも少し変わります。前は「書いた」で終わっていたのが、いまは「読まれるかな」まで考えるようになりました。それが良いことなのかはまだ分かりませんが、**続ける理由にはなっています**。

## Search Consoleは、まだこれから

正直に書くと、**Search Consoleのほうはまだほとんど見ていません**。

登録して、サイトマップを送って、そこで止まっています。画面を開いてグラフを眺めたことはありますが、**どう読めばいいのかが分かっていません**。

ただ、いま分かっている範囲でも、ここを見るとおもしろそうだなと思っているものはあります。

- **どんなことばで検索されて出てきたのか** — 自分が意識していなかったことばで出ていたら、それはヒントになりそう
- **出ているのにクリックされていないページ** — タイトルや説明文が弱いのかもしれない
- **そもそも検索結果に出ていないページ** — まだGoogleに読まれていない可能性がある

このへんは、**しばらく記事が溜まってからのほうが意味がありそう**なので、いまは急いでいません。数記事しかない状態で順位を眺めても、たぶん何も分かりません。

## 続けると、何が身につくらしい

きっかけはYouTubeでした。「ブログを続けるとビジネスの勉強になる」という話を見かけて、そんなものかなと思っていました。

自分でやってみると、**確かにいくつかは分かる気がしてきました**。調べたものも含めて並べると、こんな感じです。

| 身につくらしいもの | ブログのどこで、それをやっているのか |
| --- | --- |
| 集客 | 検索で見つけてもらう。どのことばで探されているかを考える |
| 文章力 | 分かっていない人に向けて、順番に説明する |
| WEBマーケティング | 出た数字を見て、次に何を変えるかを決める |
| コンテンツ制作 | 題材を決めて、図を作って、最後まで出す |
| 数字の読み方 | 数字を見て、それが何を意味しているのかを考える |
| 仮説と検証 | 「たぶんこうだろう」で試して、結果を見る |
| 継続する仕組み作り | 面倒な部分を自動化して、書くところだけ残す |

いま自分がやっているのは、ほとんど最後の2つです。[GitHub Actionsで自動デプロイ](/blog/2026-09-18-github-actions-deploy/)にしたり、[スキルを作って書く手順をまとめたり](/blog/2026-09-21-claude-code-skill/)しているのは、要するに**続けやすくするため**です。

上の表を作ってみて思ったのは、**どれも「やろうと思ってやる」ものではなさそう**ということでした。続けていると、必要になった順に触ることになる。集客を勉強しようと思って始めた人はたぶん少なくて、続けているうちに「読まれないな」と思って調べ始めるのだと思います。

<Callout type="tip">
	ひとつだけ、いまのうちに気をつけようと思っていることがあります。**数字を見る日を決めておく**ことです。毎日見ていると、数が動かない日に落ち込んで終わりそうなので。週に1回くらいがちょうどよさそうです。
</Callout>

## とりあえず続けてみる

ビジネスをやるつもりは、いまのところまったくありません。

ただ、**入れてよかったな**と思っています。数字が見えるようになっただけで、書くことが少し楽しくなりました。1日数人でも、いるといないとでは全然違います。

しばらくは、こんな感じでやってみます。

- 数字は**週に1回**だけ見る
- Search Consoleは、**記事が20本くらい溜まってから**ちゃんと読む
- 自分のアクセスが混ざっていないか、**たまに確認する**

続けていたら、そのうち「読まれない理由」を調べることになると思います。そのときにまた書きます。
