**Keychronからトラックボールが出ています。**

キーボードのメーカーという印象しかなかったので、見つけたときは「え、出すんだ」と思いました。そして仕様を読んで、**これは買うしかないのでは**という気分になっています。

理由はひとつだけです。**設定がマウス本体に保存される**こと。

いま使っているトラックボールへの不満が、そこにしかなかったからです。

## いまのトラックボールには、おおむね満足している

使っているのは**ロジクールのMX ERGO**です。

これは本当に買ってよかったと思っています。

- **手首の痛みが消えた** — マウスを動かさなくていいので、腕ごと動かす必要がない
- **ボタンをカスタマイズできる** — よく使う操作を親指まわりに置ける
- 場所を取らない — 本体が動かないので、狭い机でも困らない

特に手首です。普通のマウスを使っていたころは、夕方になると手首が重くなっていました。トラックボールにしてから、その感じがなくなりました。

**道具を変えるだけで体が変わることがある**、というのはここで学びました。[キーボードを分割にするか迷っている話](/blog/2026-09-20-realforce-rs1/)も、結局は同じ動機です。

## 不満は1点だけ。職場のPCにつなぐと、設定が消える

満足はしているのですが、ひとつだけ引っかかっていることがありました。

**職場のPCにBluetoothでつなぐと、ボタンの設定がデフォルトに戻ります。**

自分のPCではちゃんと効いています。割り当てたとおりに動きます。ところが同じマウスを職場のPCにつなぐと、**カスタマイズする前の動き**に戻ってしまう。

最初はマウスが壊れたのかと思いました。そうではなくて、**そもそもマウスの中に設定が入っていなかった**わけです。

<SettingsStorageLocation />

使っているMX ERGOには、**オンボードメモリがありません**。ボタンの割り当ては `Logi Options+` というソフトが持っていて、そのソフトが入っているPCでだけ効きます。

言われてみれば当たり前でした。設定はマウスではなく、**PCの中にあった**わけです。

<Callout type="note">
	設定そのものは引き継げます。`Logi Options+` はアカウントに設定を保存できるので、新しいPCでも同じソフトを入れてログインすれば戻ってきます。**あくまで「ソフトを入れられるPCなら」の話**です。
</Callout>

そして私の場合、そこが詰みでした。**職場のPCには、勝手にソフトを入れられません。**

会社から支給されているPCなので、当然といえば当然です。「便利だから入れさせてください」と言って通る話でもありません。

<Callout type="warning">
	ここは会社によってルールが違います。ソフトを入れていいかどうかは、勝手に判断せずに確認したほうが安全です。私の場合は入れられないので、マウス側で解決するしかありませんでした。
</Callout>

つまり私が欲しかったのは「設定を引き継ぐ方法」ではなくて、**そもそもPC側に何も入れなくていいマウス**でした。

## Keychron T1 HE は、マウス側が覚えている

そこで出てきたのが、**Keychron初のトラックボール「Keychron T1 HE」です**。

こちらは**オンボードメモリを持っていて、設定がマウス本体に保存されます**。どのPCにつないでも、割り当てたとおりに動く。

設定はブラウザで動く**Keychron Launcher**から行います。アプリのインストールも要りません。

Keychronのキーボードを触ったことがある人には、たぶん見覚えのある話だと思います。**キーボードでずっとやってきたこと（設定は本体が持つ）を、そのままマウスに持ってきた**という理解をしています。

<Callout type="tip">
	ここは考え方の違いだと思っています。ロジクールは「ソフトで便利にする」方向、Keychronは「本体で完結させる」方向。どちらが優れているというより、**自分でソフトを入れられるPCだけで使うならロジクール、入れられないPCを行き来するならKeychron**、という向き不向きの話に見えます。
</Callout>

## どんな製品なのか

調べた範囲でまとめます。

| 項目 | 内容 |
| --- | --- |
| 名前 | Keychron T1 HE（Keychron初のトラックボール） |
| タイプ | 親指操作タイプ |
| ボール | 34mm、セラミック支持球 |
| 設定の保存先 | **マウス本体（オンボードメモリ）** |
| 設定方法 | Keychron Launcher（ブラウザで動く。アプリ不要） |
| 接続 | 有線 / 2.4GHz無線 / Bluetooth の3通り |
| 特徴的な機構 | ボールの位置を前後左右に最大3.5mm、高さ方向に最大3mm動かせる |
| スイッチ | Keychron MagOptic Switch（最大1億クリック） |
| カラー | スケルトン / ブラック / ホワイト |

個人的におっと思ったのが、**ボールの位置を動かせる**ところです。

親指トラックボールは「親指の位置が合うかどうか」が全てだと思っています。合わないと結局手首をひねることになるので、**手の大きさに合わせてボールの位置をずらせる**のは、かなり実用的な機構に見えます。

</Callout>

## 買い方が特殊で、そもそもいま買えない

ここで大事なことがあります。**これは店頭に並んでいる製品ではありません。**

日本では[クラウドファンディング](https://costory.jp/cf-published-sku-groups/1564464666)という形での先行販売でした。支援額は超早割で税込7,480円、早割で7,744円です。

そして調べていて分かったのですが、**その募集はもう終わっていました**。超早割が6月14日まで、早割が6月30日まで。いまページを開くと「このプロジェクトは終了しました」と出ます。

配送は9月の予定でしたが、9月25日付で遅延のお知らせが出ていました。支援した人のところにも、まだ届いていないようです。

一般販売がいつ始まるのかは、探した範囲では見つけられませんでした。

<Callout type="warning">
	つまり、**いまは買えません**。ここに書いた価格もクラウドファンディング当時のものです。状況は変わるはずなので、買うときは必ず自分で最新の情報を確認してください。
</Callout>

## 欲しいのに、買えない

ここまで書いておいて何ですが、**まだ買っていません**。正確には、**いま買う手段が見つかっていません。**

気づくのが遅かったということになります。「これは買うしかない」と思った時点で、募集はとっくに終わっていました。

とはいえ、MX ERGOはまだ元気に動いています。手首の問題も解決したままです。**困っているわけではなくて、もっと良くなりそうだと思っているだけ**なので、待てばいい話ではあります。

一般販売が始まったら、たぶん買います。職場でマウスの設定が戻るたびに地味にストレスが溜まっていたので、それが毎日消えるなら、7千円台という金額は安いほうだと思っています。

買えたら、使い心地をまた書きます。
