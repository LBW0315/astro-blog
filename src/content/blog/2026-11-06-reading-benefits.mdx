[前の記事](/blog/2026-11-05-reading-brain/)で、読書が苦手な私が、スマホを別の部屋に置いて5分だけ本を読んでいる話を書きました。

その流れで、読書の効果について話している動画を2本見ました。1本は「読書で脳に起きる5つの変化」、もう1本は「読書のメリット20個」を紹介するものです。

聞いていると、読書にはすごい力がありそうです。感情に振り回されなくなる。集中力が上がる。共感力が育つ。立ち直る力がつく。発想が柔らかくなる。

ただ、あまりにいいことばかりなので、**これは全部本当なんだろうか**と気になりました。そこで、動画に出てきた効果を1つずつ調べて、根拠の強さで分けてみました。

## 動画に出てきた効果

まず、2本の動画に出てきた効果を、重なるものをまとめて並べてみます。

- **頭の力**：語彙力、論理的に考える力、鵜呑みにしない力、集中力、想像力、問題解決能力、表現力、発想の柔らかさ
- **心の力**：感情を制御する力、ストレスが和らぐ、自分の感情を整理できる、立ち直る力（レジリエンス）、自己肯定感、不安が減る、やる気が出る
- **人との関わり**：他人の立場で考えられる（共感）、会話が弾む、価値観が広がる
- **暮らし**：スマホ依存が減る、習慣にしやすい、一生楽しめる、お金がかからない

数えると20個を超えます。これだけあると、読まない理由がないように思えてきます。

## 根拠の強さで3つに分ける

調べてみると、同じ「読書の効果」でも、**研究でしっかり確かめられているものと、そうでないものが混ざっていました**。そこで、3つに分けてみました。

<Callout type="note">
	私は研究者ではないので、論文や、論文を紹介した記事を読める範囲で調べた結果です。「確かめられていない」は、「間違っている」という意味ではありません。私が調べた範囲では、それを確かめた研究が見つからなかった、という意味です。
</Callout>

### 研究の裏づけがしっかりしているもの

| 効果 | 分かっていること |
| --- | --- |
| 語彙や読む力と関係がある | 幼児から大学生までを対象にした99件の研究をまとめた分析で、ふだん本を読む量が多い人ほど、語彙や読解の力が高かった。年齢が上がるほど、その関係は強くなっていた。読む量と力が互いに伸ばし合う関係と考えられていて、読書だけが原因とは言い切れない |
| 思い出すと記憶に残る | 同じ文章を読み直すより、読んだ内容を思い出すテストをしたほうが、1週間後によく覚えていた。同じ結果がくり返し確かめられている |

意外だったのは、2つ目です。これは読書そのものの効果というより、**読んだあとに思い出す**ことの効果です。

動画でも、本を閉じたあと30秒だけ「今日この本から得た、いちばん大事な1つは何か」と自分に聞く習慣がすすめられていました。いちばん根拠がしっかりしていたのは、読んでいる最中ではなく、読み終えたあとの話でした。

### 研究はあるが、言える範囲が限られるもの

| 効果 | 分かっていること | 気をつけたい点 |
| --- | --- | --- |
| 人の気持ちを読み取る力（共感） | 14件の実験をまとめた分析で、小説を読んだ人は、読まなかった人などより、人の気持ちを読み取る課題の成績が少しだけ高かった | 差は小さい。日常の共感力が長く育つところまでは確かめられていない |
| 脳のつながりが変わる | 大学生約20人が9日間かけて小説を読んだ実験で、読んでいる期間に脳のつながりに変化が見られた。読み終えたあとも数日残ったのは、体の感覚に関わる部分の変化だった | 少人数の実験。能力が伸びたかを測った研究ではなく、どのくらい長く続くかも分かっていない |
| 頭の働きの衰えがゆっくりになる | 高齢者294人を調べた研究で、読書や書くことなど頭を使う活動がいちばん多い人たちは、平均的な人より記憶や思考の衰えが約3割ゆっくりだった | 観察した研究なので、読書が原因とまでは言えない。読書だけの効果でもない |
| 長生きと関係がある | 50歳以上の約3600人を最長12年追った調査で、本を読む人は読まない人より死亡リスクが約20%低かった | 観察した調査なので、読書が原因とまでは言えない |
| 寝つきを邪魔しにくい | 寝る前に光る端末で読むと、紙の本で読んだときより寝つきが遅かった | 紙と端末の比べ方の話で、読書をしないときと比べたものではない |
| 気分の落ち込みや不安が軽くなる | 認知行動療法などの考え方にもとづいたセルフヘルプ本を読む「読書療法」で、軽い〜中くらいのうつや不安がやわらいだという研究が複数ある | 研究で使われた決まった本の話。趣味の読書に同じ効果があるかは別 |
| 白黒をつけたがる気持ちが和らぐ | 100人の実験で、短い小説を読んだ人は、エッセイを読んだ人より、すぐに結論を出したがる気持ちが下がった | あとで行われた111人の実験では、同じ差が出なかった |

ストレスや長生き、寝つきの話は、[前の記事](/blog/2026-11-05-reading-brain/)でも少し詳しく書いています。

こうして並べると、**結果や確かさには幅があって、動画で聞いたほど強くはない**、という印象です。効果が小さいもの、原因かどうか分からないもの、決まった本に限られるもの、再現されなかったものが混ざっています。「読書で〇〇が飛躍的に強くなる」というより、「関係がありそう」「条件によっては効果が出た」くらいが正確なところでした。

### まだ確かめられていないもの

| 動画での説明 | 調べて分かったこと |
| --- | --- |
| 6分の読書で、ストレスが68%下がる | 報道はあるが、元の論文や報告書が見つからず、人数や測り方が分からない。この数字は裏づけには使えない |
| 前頭前野が鍛えられて、感情に振り回されなくなる | 読書中に脳のいろいろな部分が働くこと自体はあり得る。でも、読書で感情を制御する力が強くなる、と確かめた研究は見つからなかった |
| ワーキングメモリが鍛えられて、日常でも集中力が続く | 読むときにワーキングメモリを使うのは確か。ただ、それが日常の集中力にまで広がる、というところは見つからなかった |
| 短い動画で集中力が落ちる | 関係を調べた研究はあるが、原因と結果なのかは、まだはっきりしていない |
| 困難から立ち直る力（レジリエンス）が育つ | 自分の人生を物語として捉える考え方は心理学にある。ただ、読書でその力が育つと確かめた研究は見つからなかった |
| 想像力や創造性が広がる | 上の111人の実験で、発想の柔らかさなども調べたが、小説とエッセイで差は出なかった |
| 表現力が上がる・会話が弾む | 読む量と語彙の関係からの推測。会話が弾むところまで調べた研究は見つからなかった |
| 論理的に考える力・鵜呑みにしない力・問題解決能力・価値観が広がる | 読書との関係を直接確かめた研究は見つからなかった |
| 自己肯定感が高まる・やる気が出る・スマホ依存が減る | 体感の話として語られていた。研究は見つからなかった。不安については、上の読書療法の研究がある |

この中には、私も「そうだったらいいな」と思うものが多いです。体感として、そう感じる人がいるのも分かります。ただ、**研究で確かめられた効果として受け取るのは、まだ早い**ようです。

### 研究がなくても言えること

一方で、研究を持ち出すまでもなく、確かなこともあります。

- **お金がかからない**：図書館を使えば、ほとんど無料で読める
- **1人でできる**：相手も場所も、特別な道具もいらない
- **年齢を問わない**：体力が落ちても、環境が変わっても続けられる
- **少しから始められる**：1日5分でも、1冊を何日かけて読んでもいい

動画で「習慣にしやすい趣味」「一生楽しめる」「コスパ最強の自己投資」と言われていたのは、このあたりのことです。ここは、そのとおりだと思います。

## 私が感じている変化

では、私自身はどうか。

5分読書を始めてから感じているのは、**気持ちが落ち着く**ことです。

ストレスが68%下がる、という数字は元がはっきりしないので、裏づけとしては使えません。それでも、スマホを別の部屋に置いて本を開くと、気持ちが落ち着く。これは、数字がなくても私の実感としてあります。

集中力が上がったとか、感情に振り回されなくなったとかは、まだ分かりません。始めたばかりなので、今はそれで十分だと思っています。

## 読んだら、妻にひと言で説明できるように

もう1つ、意識していることがあります。

**妻に本のことを聞かれたときに、内容をひと言で説明できるように頑張っています。**

説明が長いと、くどくなってしまうからです。だから、いちばん大事なところだけを、短く言えるようにしておく。

<ReadRecallTell />

調べてみて気づいたのですが、これは、いちばん根拠がしっかりしていた「思い出すと記憶に残る」と、思い出すという点で共通していました。

ひと言にまとめるには、読んだ内容を思い出して、その中からいちばん大事なところを選ばないといけません。動画ですすめていた「今日この本から得た、いちばん大事な1つは何か」という問いとも、やっていることは近いです。研究の実験は、妻への説明そのものを確かめたわけではありませんが、思い出す練習にはなっていそうです。

私の場合は、自分に問いかけるより、**妻に聞かれるかもしれない**と思っているほうが続きそうです。

## おわりに

調べてみると、読書の効果は、動画で聞いたほど万能ではありませんでした。研究の裏づけがしっかりしているのは、読む量と語彙や読む力との関係と、読んだあとに思い出すと記憶に残ることくらい。ほかは、効果が小さかったり、原因かどうか分からなかったり、まだ確かめられていなかったりします。

でも、だから読書に意味がない、とは思いませんでした。

気持ちが落ち着く。お金がかからない。1人で、5分からできる。そして、読んだあとに妻にひと言で話すことは、記憶に残す助けになりそうです。これだけでも、続ける理由としては十分です。

すごい効果を期待しすぎず、5分の読書と、ひと言の説明を続けていこうと思います。読書のメリットが気になっている人の参考になれば幸いです。
