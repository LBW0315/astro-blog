Astroで記事を書くときに使える、基本的なMarkdown記法をまとめました。

## 見出し

HTMLの`<h1>`から`<h6>`に相当する、6段階の見出しを作成できます。`<h1>`が最も大きく、`<h6>`が最も小さい見出しです。

# 見出し1

## 見出し2

### 見出し3

#### 見出し4

##### 見出し5

###### 見出し6

## 段落

文章は、空行を挟むことで段落に分けられます。内容のまとまりごとに段落を分けると、長い記事でも読みやすくなります。

一つの段落には、一つの話題をまとめるのがおすすめです。

## 画像

### 記法

```markdown

```

## 引用

ほかの資料や発言を引用するときは、行の先頭に`>`を付けます。引用の中でもMarkdown記法を利用できます。

### 出典なしの引用

#### 記法

```markdown
> これは引用文のサンプルです。<br>
> 引用の中でも**太字**や*斜体*を使えます。
```

#### 表示例

> これは引用文のサンプルです。<br>
> 引用の中でも**太字**や*斜体*を使えます。

### 出典付きの引用

#### 記法

```markdown
> 良い文章は、読み手への小さな案内板です。<br>
> — <cite>サンプル著者[^1]</cite>
```

#### 表示例

> 良い文章は、読み手への小さな案内板です。<br>
> — <cite>サンプル著者[^1]</cite>

[^1]: この文章はMarkdown記法を示すためのサンプルです。

## 表

### 記法

```markdown
| 斜体     | 太字     | コード   |
| -------- | -------- | ---------- |
| *斜体*   | **太字** | `コード` |
```

### 表示例

| 斜体     | 太字     | コード   |
| -------- | -------- | ---------- |

## コードブロック

### 記法

3個のバッククォートでコードを囲みます。最初のバッククォートの直後に言語名を書くと、構文が色分けされます。

````markdown
```html
<!doctype html>
<html lang="ja">
  <head>
    <meta charset="utf-8" />
    <title>HTML5文書の例</title>
  </head>
  <body>
    <p>こんにちは！</p>
  </body>
</html>
```
````

### 表示例

```html
<!doctype html>
<html lang="ja">
  <head>
    <meta charset="utf-8" />
    <title>HTML5文書の例</title>
  </head>
  <body>
    <p>こんにちは！</p>
  </body>
</html>
```

## リスト

### 番号付きリスト

#### 記法

```markdown
1. 一つ目の項目
2. 二つ目の項目
3. 三つ目の項目
```

#### 表示例

1. 一つ目の項目
2. 二つ目の項目
3. 三つ目の項目

### 箇条書き

#### 記法

```markdown
- リスト項目
- 別の項目
- もう一つの項目
```

#### 表示例

- リスト項目
- 別の項目
- もう一つの項目

### 入れ子のリスト

#### 記法

```markdown
- 果物
  - りんご
  - みかん
  - バナナ
- 乳製品
  - 牛乳
  - チーズ
```

#### 表示例

- 果物
  - りんご
  - みかん
  - バナナ
- 乳製品
  - 牛乳
  - チーズ

## その他の要素 — abbr、sub、sup、kbd、mark

### 記法

```markdown
<abbr title="Graphics Interchange Format">GIF</abbr>は画像形式の一つです。

H<sub>2</sub>O

X<sup>n</sup> + Y<sup>n</sup> = Z<sup>n</sup>

保存するには<kbd>Command</kbd> + <kbd>S</kbd>を押します。

この部分が<mark>重要</mark>です。
```
